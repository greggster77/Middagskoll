# Middagskollen

Privat, mobilanpassad middagsapp exporterad för lokal drift i Home Assistant.

Installera med instruktionerna i **LAS-MIG-FORST.md** i ZIP-filens rot. Tekniska startinstruktioner och felsökning finns i **DOCS.md** i den här mappen.

500 recept, sökning på namn och ingredienser, veckoplan, portionsanpassning, inköpslista, budget, automatiska riktpriser och egna priser, hemmalager, EAN-kamera, pasta och relevanta erbjudanden ingår.
